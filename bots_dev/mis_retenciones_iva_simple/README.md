# Mis Retenciones IVA SIMPLE

Bot de desarrollo para seleccionar `Exportar para IVA SIMPLE`, probar las tres operaciones y descargar los dos formatos disponibles: el archivo IVA SIMPLE y el XLS.

El rango acepta como máximo hasta el último día del mes siguiente a `desde`.

Las credenciales de prueba se pasan exclusivamente por variables de entorno. No se guardan en este directorio.
